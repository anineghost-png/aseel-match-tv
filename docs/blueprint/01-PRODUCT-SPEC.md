# PRODUCT SPEC — ASEEL MATCH TV

## Product sentence
A personal Arabic football television interface for PS4 that turns authorized IPTV/sports data into a one-click match experience.

## User promise
"افتح الموقع، شوف المباراة، اضغط X."

## Primary persona
Single user in Iraq, watching football on a TV through PlayStation 4.

## Preferences
- FC Barcelona is primary.
- La Liga is primary.
- UEFA Champions League and Europe's top five leagues are important.
- Arabic-only day-to-day UX.
- Asia/Baghdad time.
- Football only; no general smart-TV clutter.

## Jobs to be done
- Know what's live now.
- Know Barcelona's next match.
- Start the correct authorized broadcast without browsing channels.
- Recover from a weak source automatically when alternatives in the user's authorized provider exist.
- See current score/status without opening another site.

## Non-goals v1
- Movies/series launcher
- weather dashboard
- social feed
- web crawling for IPTV
- DRM bypass
- PS4 jailbreak/homebrew
- mobile remote
- multi-user accounts

## UX principles
1. Match-first, not channel-first.
2. No server jargon on the TV.
3. Conservative correctness: "غير مؤكد" beats a wrong automatic choice.
4. One-screen comprehension from couch distance.
5. Focus never jumps during refresh.
6. Always recover gracefully when data is unavailable.
