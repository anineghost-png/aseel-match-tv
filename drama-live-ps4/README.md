# Drama Hub — PS4

A controller-first Arabic RTL browser portal for launching an authorized Drama Live web source from PlayStation 4.

## Design goals
- One permanent HTTPS bookmark on PS4.
- No phone, Termux, laptop, or home server dependency.
- D-pad + Cross select + Circle/back navigation.
- Large 10-foot TV UI and strong focus state.
- Local-only preferences, favorites, FG code reminder, and recent-use state.
- No stream URLs, IPTV credentials, or media catalogs stored in this project.
- Drama Live remains the media player and source UI; this portal does not scrape or bypass it.

## Runtime
Static HTML/CSS/JS. No build step and no secrets.
