# ASEEL MATCH TV — PS4 Release Candidate 1

واجهة عربية RTL لمباريات كرة القدم، مخصصة لاختبار متصفح PS4 ويد DUALSHOCK 4 على شبكة منزلية موثوقة. **جاهزة لبدء اختبار M9؛ نجاح الفيديو والتحكم على PS4 غير مُثبت بعد.**

مصدر الحقيقة: https://github.com/anineghost-png/aseel-match-tv — الفرع `work/ps4-foundation`. تاريخ M0–M8 محفوظ. نقطة الاستئناف المتحققة: `0be31703c9453caae7a61450c09286b323c08e09` وتشمل إصلاح FFmpeg في CI.

## التشغيل بأقل خطوات
المتطلبات على الكمبيوتر: Node.js 24+ وnpm، وFFmpeg متوفر عبر PATH. الكمبيوتر وPS4 على الشبكة نفسها.

```sh
npm ci
npm run ps4
```

هذا الأمر يحافظ على مفاتيح `.env` الموجودة، ينشئ إعدادًا ومفتاح إدارة محليًا عند الحاجة، يفعّل `HOST=0.0.0.0`، يبني الخادم، ويولّد فيديو اختبار قانونيًا 720p H264/AAC ثم يشغّل التطبيق. يعمل توليد الفيديو على Windows/Linux/macOS دون اشتراط Bash. أبقِ نافذة التشغيل مفتوحة.

**افتح على PS4 العنوان الذي تطبعه النافذة بجانب `PS4 candidate URL`**، مثل `http://192.168.1.20:3000`. المثال ليس عنوان جهازك. عند ظهور أكثر من عنوان اختر محول Wi-Fi/Ethernet المتصل بشبكة PS4، وتجاهل VPN والمحولات الافتراضية. اسمح للمنفذ 3000 على الشبكة الخاصة فقط؛ لا تعمل port forwarding.

- `/compat`: حفظ قدرات الجهاز واختبار HLS الأصلي ثم HLS.js إن توفر. لا تسجّل نجاحًا قبل تقدم الفيديو فعليًا.
- `/controller`: اختبار اليد والأسهم والاختيار.
- `/`: الشاشة الرئيسية، أضفها إلى الإشارات المرجعية.
- `/admin`: اقرأ ADMIN_TOKEN محليًا من `.env` وأدخله في الصفحة؛ لا ترسله ولا تحفظه في Git.
- `/health`: حالة خادم بسيطة بدون أسرار.

للتشغيلات اللاحقة: `npm start`. لإعادة إنشاء الفيديو فقط: `npm run media`. للإيقاف: Ctrl+C. إن تغيّر IP الكمبيوتر استخدم العنوان المطبوع حديثًا.

## عند حدوث مشكلة
- `STARTUP_FAILED`: تحقق من Node، مفتاح ADMIN_TOKEN (32–256 محرف ASCII دون مسافات)، المنفذ ومجلد البيانات القابل للكتابة. لا تطبع `.env` في تقارير الدعم.
- FFmpeg غير موجود: أضفه إلى PATH ثم أعد `npm run ps4`.
- PS4 لا يصل للخادم: اختبر العنوان من هاتف على الشبكة نفسها، راجع جدار الحماية والشبكة الخاصة، وتأكد أن نافذة الخادم مفتوحة.
- فشل الفيديو: لا تعتبره نجاحًا؛ صدّر التشخيص من الإدارة وسجّل النتيجة في `docs/PS4_ACCEPTANCE.md`.
- لا توجد مصادر مؤكدة: المتوقع قبل إعداد مزوّد مصرح به. لا يتطلب اختبار القدرات والفيديو المحلي أي IPTV أو API key.

## البيانات والأمان
DEMO_MODE=true يظهر تنبيهًا واضحًا؛ بياناته اصطناعية. للبيانات الحقيقية اجعله false وأضف المفتاح محليًا؛ football-data هو المفضّل عند إعداد المزوّدين. المصادر المصرح بها فقط عبر /admin؛ حدد مضيفيها في MEDIA_ALLOWED_HOSTS أو MEDIA_LAN_HOSTS. لا تُكشف روابطها في خطط التشغيل أو التشخيص. بيانات الإنتاج لا تستبدل بأمثلة عند فشل الاتصال.

LAN موثوق فقط، وليس نشرًا عامًا: لا TLS أو عزل مستخدمين عامًا. `.env` وdata/ والقوائم الخاصة خارج Git. الملفات المحلية ليست مشفّرة. لا تتجاوز هذه النسخة DRM ولا تبحث عن بث غير مصرح به.

## التحقق
```sh
npm run check
npm run media
npm run test:browser
npm audit
```
على جهاز تطوير جديد ثبّت متصفح الاختبار مرة واحدة: `npx playwright install chromium`. اختبار فك H264/AAC يُتخطّى صراحة عند عدم دعم المتصفح؛ لا يعني ذلك نجاح PS4.
